
# workplace 프로젝트 구조

`workplace`는 Java 17 + Gradle 기반 인증 서버입니다. HTML 화면, 인증 서비스, MariaDB 접근 코드가 하나의 `app` 모듈에 들어 있습니다.

```mermaid
flowchart TB
    subgraph Project["workplace 프로젝트"]
        Gradle["Gradle 설정<br/>settings.gradle · gradle.properties<br/>gradlew · gradle/"]
        Build["app/build.gradle<br/>Java 17 · 실행 클래스 지정"]

        subgraph App["app/src/main"]
            subgraph Resources["resources/web — 화면"]
                Login["login.html"]
                Signup["signup.html"]
                Static["style.css · app.js"]
            end

            subgraph Java["java/workplace — 서버"]
                Server["SimpleAuthServer.java<br/>HTTP 서버 :8080"]
                Service["AuthService<br/>회원가입 · 로그인"]
                Repo["UserRepository 인터페이스"]
                Jdbc["JdbcUserRepository<br/>SQL 실행"]
                User["User<br/>사용자 데이터"]
                Session["SESSION_STORE<br/>메모리 세션 저장소"]
                JWT["JwtUtil<br/>JWT 발급 · 검증"]
                Example["DbExample.java<br/>DB 연결 및 테이블 조회 예제"]
            end
        end
    end

    Browser["브라우저"]
    DB[("MariaDB :53301<br/>sql_db.users")]
    External["외부 서비스 :8008<br/>로그인 성공 후 이동 대상"]

    Gradle --> Build
    Build --> Server
    Browser <-->|"화면 · 정적 파일"| Server
    Server --> Resources
    Browser -->|"회원가입 · 로그인 · 인증 확인 · 로그아웃"| Server
    Server --> Service
    Service --> Repo
    Jdbc -.->|"구현"| Repo
    Jdbc --> DB
    Service --> User
    Server --> Session
    Server --> JWT
    Example --> DB
    Server -.->|"로그인 성공 응답에 이동 URL 포함"| External
```

`AuthService`, `UserRepository`, `JdbcUserRepository`, `User`, `JwtUtil`은 모두 `SimpleAuthServer.java` 내부에 선언되어 있습니다.

현재 코드에는 로그인 연결, 세션 조회, JWT 검증 연결, 인증 거부 조건, BCrypt 처리에 TODO가 남아 있으므로, 다이어그램의 인증 흐름은 일부 미완성 상태입니다.
