# API 명세

8080 인증 서버와 8001 외부 RAG 서버의 기존 명세를 유지하고, 8008 음성 서버는 [voice-ai_code/api.json](voice-ai_code/api.json)의 OpenAPI 3.1.0을 기준으로 반영했다. response의 JSON은 형식을 설명하는 예시다.

## 8008 응답 스키마

아래 필드와 필수 여부는 `api.json`의 `components.schemas` 기준이다. `string 또는 null`인 선택 필드는 생략하거나 null일 수 있다.

### VoiceAnswer

`POST /voice-query`, `POST /voice-query-text`의 성공 응답이다.

| 필드 | 타입·제약 | 필수 |
| --- | --- | --- |
| `answer` | string, 1~12,000자 | 예 |
| `sources` | `Source[]` | 예 |
| `needs_review` | boolean | 예 |
| `handoff` | boolean | 예 |
| `transcript` | string | 예 |
| `audio_url` | string 또는 null | 아니요 |
| `warning` | string 또는 null | 아니요 |
| `mode` | string, 허용값 별도 지정 없음 | 예 |
| `latency_ms` | integer | 예 |

### Source

| 필드 | 타입 | 필수 |
| --- | --- | --- |
| `doc` | string | 예 |
| `article` | string 또는 null | 아니요 |
| `page` | integer, string 또는 null | 아니요 |

### TranscriptReview

`POST /voice-transcribe`의 성공 응답이다.

| 필드 | 타입·기본값 | 필수 |
| --- | --- | --- |
| `raw_transcript` | string | 예 |
| `corrected_question` | string | 예 |
| `changed` | boolean | 예 |
| `confirmation_required` | boolean, 기본 true | 아니요 |
| `warning` | string 또는 null | 아니요 |

### HTTPValidationError

8008의 모든 명세 경로에 선언된 422 응답이다.

```json
{
  "detail": [
    {
      "loc": ["body", "question"],
      "msg": "Field required",
      "type": "missing"
    }
  ]
}
```

`detail`은 선택 배열이며, 각 검증 오류의 `loc`, `msg`, `type`은 필수다. `loc`의 각 원소는 문자열 또는 정수다. 위 JSON은 필수 질문 누락을 설명하는 예시다.

## 공통 규칙

- Java API의 미지원 메서드는 `405`, `Method Not Allowed` 일반 텍스트를 반환한다.
- FastAPI 입력 검증 오류는 `422`, `{"detail":[{"loc":[...],"msg":"...","type":"..."}]}` 형태다. 업무 오류의 `detail`은 문자열이다.
- `ACCESS_TOKEN`은 HttpOnly 쿠키다. JWT 검증은 HS256, 동일한 `JWT_SECRET`, 발급자 `simple-auth-server`를 사용한다. 사용자 정보는 `sub`, `username`에서 읽는다.
- 8008의 응답 스키마가 `{}`인 경로는 JSON 파일만으로 응답 필드를 확정할 수 없다. 이전 문서의 응답 예시와 추가 오류 코드는 해당 행에서 제거했다.
- 8008의 인증 파라미터는 OpenAPI에서 `required: false`다. 이것만으로 실제 API가 익명 호출을 허용한다고 판단할 수 없으며, `authorization`의 Bearer 형식·우선순위·401 응답은 JSON에 명시되어 있지 않다.
- 현재 `/rag-query`는 `top_k`에 1~4를 넣어도 내부에서 최소 5로 보정한다.
