# 독립 RAG 모듈 최초 평가

평가일: 2026-10-23 (Asia/Seoul)

## 수행 범위

기존 FAISS의 「Attention Is All You Need」 44개 청크와 새 `rag_agent.py`를 연결했다.
원문을 읽고 질문·기대 근거·답변 요점을 먼저 작성한 뒤 실제 OpenAI 호출을 수행했다.
기존 API·HTML·RAG 모듈의 검색 전략과 저장소 파일은 변경하지 않았다.

평가 실행기, 질문 세트, 원문 청크 목록, 결과·설정·리뷰 파일을 추가했다.
서버를 실행하지 않고도 동일한 질문 세트로 다시 평가할 수 있다.

## 결과

| 항목 | 결과 |
|---|---|
| 질문 | 답변 가능 20개 + 답변 불가 4개 |
| 실제 호출 성공 | 24/24 |
| 기대 근거 Hit@5 | 13/20 = 65% |
| 근거 그룹 재현율 | 65% |
| 컨텍스트 근거 그룹 재현율 | 65% |
| MRR | 약 0.527 |
| 전체 응답 시간 중앙값 | 약 1.78초 |
| 기존 인덱스 변경 | 없음, 전후 파일 해시 동일 |
| 오프라인 테스트 | 기존 9개 + 평가 로직 5개, 총 14개 통과 |

검색 지표는 답변 가능 질문 20개 기준이다. 시간은 새 함수 전체 실행이며 STT/TTS는 제외한다.
LLM 첫 토큰 시간은 측정하지 않았다. 단일 문서·소규모 질문 세트의 최초 기준선이다.

## 결과에서 확인한 문제

1. **한국어 질문에서 필요한 근거를 놓치는 경우가 있다.** 마스킹(q03), FFN 내부 차원(q08),
   위치 인코딩(q09), 사인파 선택 이유(q10), 드롭아웃(q16), 라벨 스무딩(q17),
   구문 분석(q20)의 사전 지정 핵심 근거가 상위 5개에 들지 않았다.
2. **검색에 실패해도 그럴듯하게 답할 수 있다.** q09는 위치 인코딩을 설명했지만 실제 전달
   자료에 해당 내용이 없고 인용도 부적절했다. 출처 ID가 존재하는 것만으로는 충분하지 않다.
3. **정답과 근거 충실성은 별개다.** 답이 원문과 맞아도 전달 근거에 없는 내용이면
   근거 기반 응답으로는 실패다. 반대로 자료가 부족하다고 유보한 답변은 전달 근거에는
   충실하더라도 원문에 정답이 있는 질문을 해결하지 못한 결과일 수 있다.
4. **이번 실행에서 컨텍스트 예산 때문에 핵심 근거가 추가로 빠지지는 않았다.** 검색과
   컨텍스트 재현율이 동일했다. 따라서 우선 검색 단계 개선을 비교할 근거가 생겼다.

답변 불가 4개는 모두 정보가 없다고 안내했다. 이는 Codex의 1차 검토 결과이며
독립적인 사람의 평가를 받지 않았다. 자세한 판정 이유는 질문별 리뷰에 남겼다.
정답 기준 역시 Codex가 원문에서 작성했으므로 사람의 추가 확인이 필요하다.

## 다음 실험 제안 — 아직 수행하지 않음

- 평가 기준을 먼저 사람이 검토한다. 특히 대체 가능한 근거와 여러 청크에 걸친 문맥을 확인한다.
- 질문 세트와 모델을 고정한 채 `top_k` 변경 효과를 비교한다.
- 한국어 질의에 핵심 영문 용어를 보완하거나 검색용 질문을 정리하는 방법을 비교한다.
- 후보 확대·재순위화 또는 키워드 결합은 실패 질문 개선과 지연 증가를 함께 측정한다.
- 단순 top-k 확대가 근거 없는 답변을 늘리지 않는지 확인한다.
- 최종 개선안이 정해지면 기존 `/rag-query`와 화면을 연결한다.
