# 음성 RAG 실제 연동 진단

- 작업일: 2026-10-26 (Asia/Seoul)
- 브랜치: rag-preprocessing-integration
- 상태: 완료 (진단·테스트 완료, 실행 서버 모드 전환 미적용)

## 요청과 목적

5173 프런트엔드에서 8008 `/voice-query-text`가 HTTP 200을 반환하지만 실제 8001 RAG를 호출하는지 의심되는 상황을 재현하고 실제 연동 가능 여부를 확인한다.

## 수행 내용 및 변경 파일

- 시작 시 Git 작업 트리는 깨끗했다. 저장소 변경은 이 작업 로그 추가뿐이다.
- `voice-ai_code/.env`의 `VOICE_RAG_MODE=demo`, `RAG_BASE_URL=http://localhost:8001`을 확인했다. 비밀정보는 출력하거나 기록하지 않았다.
- `voice_pipeline.ask_rag()`는 demo에서 로컬 가상 규정을 반환하고, live에서만 8001 `/rag-query`를 호출한다.
- 실행 중인 8008은 `uvicorn ... --reload --env-file .env`로 시작되어 있다. `.env` 변경만으로 이미 로드한 프로세스 환경이 바뀌지는 않으므로 모드 전환 시 서버 전체를 재시작해야 한다.
- `/tmp/skala_voice_diagnostic.py`에 일회성 진단 스크립트를 작성했다. 짧은 유효기간의 로컬 진단 인증을 메모리에서만 사용했다. 실제 사용자 쿠키는 사용하지 않았다.
- 실행 중인 서버와 `.env`는 변경하지 않았다. 별도 프로세스에서만 모드를 live로 바꿔 저장소의 음성 파이프라인을 호출했다.

## 검증 결과

### 실제 로컬 서버·외부 API 연동

- 5173 `/`: HTTP 200.
- 8001 `/health`: HTTP 200, `status=ok`, `corpus_revision=1`.
- 8008 인증 없는 `/voice-config`: HTTP 401로 인증 보호 확인.
- 8008 `/voice-query-text`: 진단 인증으로 HTTP 200, `mode=demo`, 가상 규정 출처, `session_id=null` 재현. 이 응답은 실제 RAG 성공의 증거가 아니다.
- 별도 live 파이프라인 → 실행 중인 8001 `/rag-query`: 실제 모델 호출 성공. 스칼라테크 휴가규정 등 출처와 세션 ID, 요청 ID, 문서 버전 1, `summary_update_status=up_to_date` 수신. 전체 첫 질문 처리 약 14.6초.
- 해당 답변은 등록 문서에 초안 또는 회사 미확정 항목이 있다는 경고와 `needs_review=true`를 포함했다. 내용의 법적 타당성을 평가한 테스트는 아니다.
- 실제 TTS API 응답 200. 생성 MP3를 실행 중인 8008에서 인증 다운로드하여 HTTP 200, `audio/mpeg`, 1,049,472바이트 확인.
- 후속 질문에서 동일한 세션 유지 및 `up_to_date` 확인. 진단 세션 종료 성공.

### 모의 자동 테스트

- `voice-ai_code`: `.venv/bin/python -m unittest discover -s tests -p 'test_voice_query.py'` — 16개 통과.
- `frontend`: `npm test` — 38개 통과. 브라우저 fetch·녹음·재생 동작을 모의한 자동 테스트이며 실제 화면 검증과 구분한다.

## 남은 작업 및 제약

- 실제 사용자 경로를 live로 전환하려면 `voice-ai_code/.env`의 `VOICE_RAG_MODE=live` 설정 후 8008 uvicorn 전체 프로세스를 종료하고 같은 실행 명령으로 다시 시작해야 한다. 테스트 요청 범위에서 현재 실행 설정은 유지했다.
- 실제 사용자 브라우저 화면, 쿠키 로그인, 마이크 STT 및 스피커 청취는 검증하지 않았다. 브라우저 자동화 연결을 시도했으나 네이티브 앱 조회가 시간 초과되어 HTTP 및 파이프라인 테스트로 진행했다.
- 진단용 음성 파일은 기존 서비스의 900초 만료 정책 대상이다.
- `frontend/README.md`의 현재 RAG 계약 불일치 설명은 현행 서버 코드와 다르다. 이번 실제 live 응답은 음성 파이프라인 스키마 검증을 통과했다. 문서는 수정하지 않았다.
