# rag-service 설계·전략 및 Python 모듈 설명 문서 추가

## 요청·목적

`rag-service` 폴더에 RAG 설계 및 전략, LangChain·LangGraph 구현 설계 및 전략, 그리고 `rag-service` 내 Python 파일들의 용도를 정리한 문서를 추가한다. 상단에는 핵심 요약을 두고 하단에는 섹션별로 구체적인 설명을 작성하며, Markdown 목차(인덱스) 링크로 섹션 간 이동이 가능하도록 구성한다.

## 실제 변경 파일

- 신규: `rag-code-template_ext/rag-service/ARCHITECTURE.md`
- 수정: `rag-code-template_ext/rag-service/README.md`
- 신규: `rag-docs/작업기록/2026-10-25_014_rag_service_설계_및_구조_문서_추가.md`
- 기존 워킹 트리에 남아 있던 다른 미커밋 변경분은 이번 작업에서 만든 것이 아니다.

## 수행 내용

1. `rag-code-template_ext/rag-service/` 내 모든 Python 파일(`rag_agent.py`, `rag_state.py`, `rag_workflow.py`, `rag_router.py`, `session_memory.py`, `rag_session.py`, `rag_api.py`)과 상위 진입점·전처리 파일(`rag_external-web_pdf_closed_llm.py`, `pdf_pipeline.py`, `ingest.py`), 그리고 `rag-docs/` 설계 문서를 대조해 `rag-code-template_ext/rag-service/ARCHITECTURE.md`를 작성했다.
2. 문서 상단에 요약(Quick Summary)과 클릭 이동이 가능한 목차(Index)를 배치하고, 각 섹션 하단에 `[↑ 목차로 돌아가기](#-목차-index)` 앵커를 넣었다.
3. 하위 섹션에는 다음 내용을 구체적으로 정리했다:
   - 전체 요청 처리 흐름도
   - `rag-service` 및 상위 연동 Python 파일별 한 줄 요약 표와 주요 클래스·함수별 상세 역할
   - 입력 유형별 처리 정책, 환각 방지·출처 인용 검증, 토큰·호출 수·시간 예산 통제 전략
   - LangChain(LCEL `RunnableLambda | RunnableBranch`, OpenAI `strict=True` 및 중첩 Union 스키마 `MemoryDecisionOutput`) 구현 전략
   - LangGraph(5개 묶음 `RagState`, 11개 노드 Mermaid 흐름도, 조건부 전이 및 재검색 종료 조건) 구현 전략
   - 세션 기억(최근 5턴 + 증분 요약), Lock·CAS 버전 관리·`request_id` 멱등성, 무중단 PDF 업로드 스냅샷 교체 전략
4. `rag-code-template_ext/rag-service/README.md` 상단에 `ARCHITECTURE.md` 바로가기 링크를 추가했다.
