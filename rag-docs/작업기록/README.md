# 작업기록

코드·문서 변경과 실행 검증을 작업 단위로 남기는 폴더다.
2026-10-23부터 기록하며, 그 이전 대화에서 수행한 작업은 최초 회고 로그에 묶었다.

## 기록 규칙

- 파일명: `YYYY-MM-DD_NNN_작업명.md`.
- 날짜: Asia/Seoul 기준. 같은 날짜의 번호는 `001`부터 순차 증가.
- 사용자 요청 하나의 연속 작업은 하나의 로그로 관리한다.
- 단순 설명만 한 대화는 제외하고 실제 변경·검증을 수행한 경우 기록한다.
- 기록에 원래 작업 시각을 확인할 수 없으면 임의의 시각을 넣지 않는다.
- 변경 파일과 확인만 한 파일을 구분하고, 실패·미완료 사항도 남긴다.
- 비밀정보는 기록하지 않는다. 상세 결과가 별도 파일에 있으면 경로로 연결한다.

## 로그 양식

```markdown
# 작업명

- 작업일: YYYY-MM-DD (Asia/Seoul)
- 브랜치: 브랜치명
- 상태: 완료 / 일부 완료 / 진행 중

## 요청과 목적

사용자가 요청한 내용과 작업 범위.

## 수행 내용 및 변경 파일

- 실제 수행한 내용과 생성·수정한 파일.
- 확인만 했거나 변경하지 않은 범위는 필요할 때 명시.

## 검증 결과

- 실행한 명령 또는 확인 방법과 결과.
- 모의 검증인지 실제 연동인지 구분.

## 남은 작업 및 제약

- 미완료 사항, 알려진 한계, 다음 단계.
```
