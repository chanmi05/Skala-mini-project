# rag-docs 문서 경로 수정

- 작업일: 2026-10-25 (Asia/Seoul)
- 브랜치: `dev-rag`
- 상태: 완료

## 요청과 목적

사용자가 문서 폴더를 `soobin-docs`에서 `rag-docs`로 변경했다고 알려 실제 위치와 참조 경로를 확인하고 수정한다. 폴더 이동은 사용자가 이미 수행한 변경이다.

## 수행 내용 및 변경 파일

- `AGENTS.md`: 작업 로그 저장 위치와 양식 안내를 `rag-docs/작업기록/` 기준으로 수정했다.
- `rag-code-template_ext/프로젝트 구조.md`: 디렉터리 트리와 세션 사용법 링크를 새 이름에 맞췄다.
- `rag-code-template_ext/rag-service/README.md`: 세션 사용법 링크를 새 문서 폴더로 수정했다.
- 이 로그는 새 작업기록 폴더에 작성했다. 과거 작업 로그의 당시 파일명·경로 서술은 변경하지 않았다. 애플리케이션 코드는 수정하지 않았다.

## 검증 결과

- 실제 `rag-docs` 폴더와 기존 작업기록 README가 존재하고 이전 폴더는 없음을 확인했다.
- 변경 문서와 `rag-docs` 내 모든 Markdown의 상대 링크 대상이 존재함을 확인했다.
- 이전 이름을 가리키는 현재 참조는 수정했으며, 과거 작업 기록에 남은 당시 경로 서술은 역사적 기록으로 유지했다.
- `git diff --check` 통과. 문서 경로 변경으로 실행 테스트·외부 API 호출은 수행하지 않았다.

## 남은 작업 및 제약

- 없음. 이후 문서와 작업 기록은 `rag-docs`를 사용한다.
