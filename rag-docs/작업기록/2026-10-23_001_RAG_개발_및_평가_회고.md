# RAG 개발 및 평가 회고

- 작업일: 2026-10-23 (Asia/Seoul)
- 브랜치: `dev-rag`
- 상태: 독립 모듈 구현·최초 평가 완료, 기존 API 연결 미완료
- 기록 방식: 로그 폴더 생성 전 대화에서 수행한 작업을 사후 요약한 기록.
  개별 작업의 정확한 시작·종료 시각은 기록하지 않는다.

## 요청과 목적

전처리·청킹과 독립된 PDF 저장소 기반 RAG를 개발한다.
기존 서버 코드를 보존한 채 별도 Python 모듈을 만들고 실제 저장소로 평가한다.

## 수행 내용 및 주요 파일

1. 기존 RAG 서버와 HTML을 실행하고 기존 논문 질의가 동작함을 확인했다.
2. `rag_query()`의 동기 호출, 검색 개수 강제, 출처 누락, 응답 필드 불일치 등을 검토했다.
3. `rag-code-template_ext/rag_agent.py`를 추가했다.
   - 입력 검증, 검색, 컨텍스트 예산, 출처 반환, 오류·시간 초과·취소 처리.
   - 저장소와 LLM을 외부에서 전달받으며 웹·수집·청킹 분기 없음.
   - 이후 한국어 주석·docstring을 추가하고 실행 코드가 동일함을 확인.
4. `rag-code-template_ext/tests/`에 RAG 및 평가 로직의 오프라인 테스트를 추가했다.
5. `rag-code-template_ext/evaluation/`에 질문 24개, 기존 청크 목록, 실제 실행기,
   결과·설정·리뷰·리포트를 추가했다.
6. `soobin-docs/`에 개발 방향, 문제·해결 전략, 사용법, 최초 평가 결과를 정리했다.

위 파일들은 이번 로그 체계 추가 이전에 이미 생성된 작업 결과다.
기존 서버·HTML·FAISS 파일은 새 모듈 연결을 위해 수정하지 않았다.

## 검증 결과

- 기존 서버: PDF 검색·OpenAI 답변 생성 성공.
- 독립 모듈 오프라인 테스트: 기존 9개 및 평가 로직 5개, 총 14개 통과.
- 실제 평가: 「Attention Is All You Need」 기존 저장소 44개 청크 사용.
- 질문 구성: 답변 가능 20개, 답변 불가 4개.
- 호출 성공: 24/24, 오류 0.
- 기대 근거 Hit@5: 13/20, 65%.
- 전체 응답 시간 중앙값: 약 1.78초. STT·TTS 및 화면 전달 시간 제외.
- 인덱스 파일의 실행 전후 해시 동일.

실제 결과: `rag-code-template_ext/evaluation/runs/baseline_20261023/`.
요약: [RAG 최초 평가](../RAG_BASELINE_EVALUATION.md).

## 남은 작업 및 제약

- 기존 `/rag-query`·화면에 새 모듈을 연결하지 않았다.
- 검색 근거 누락과 부적절한 인용 사례가 있어 품질 개선이 필요하다.
- 평가 기준과 답변 리뷰는 에이전트의 1차 검토이며 독립적인 사람의 검증은 받지 않았다.
- 스트리밍·대화 이력·음성 연동은 구현 범위에서 제외했다.
- 임베딩·적재 담당 경계와 실제 데이터 연동 계약은 추가 합의가 필요하다.
