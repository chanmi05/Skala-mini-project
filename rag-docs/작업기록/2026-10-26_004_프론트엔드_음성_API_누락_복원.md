# 프론트엔드 음성 API 누락 복원

- 작업일: 2026-10-26 (Asia/Seoul)
- 브랜치: nahyeon
- 상태: 완료

## 요청과 목적

`npm run build`에서 `transcribeAudio` export 누락으로 발생하는 빌드 오류를 해결하고, 음성 질문 확인과 답변 요청이 정상 연결되는지 확인한다.

## 수행 내용 및 변경 파일

- `frontend/src/services/voice.js`: 누락된 `transcribeAudio`, `queryAudio` export를 복원했다. 음성 파일 FormData 생성 함수에서 정의되지 않은 `options` 사용을 수정하고, API 호출과 파일 생성을 분리했다. 질문 교정 응답과 텍스트·음성 답변의 형식을 검증하도록 연결했다. 기존 `/voice-api` 프록시와 세션·요청 정보 전달을 유지했다.
- `frontend/src/composables/useVoiceInput.js`: 확인한 음성 질문의 텍스트 답변 요청에도 현재 세션·요청 정보를 전달하도록 수정했다.
- `frontend/tests/voice-api.test.js`: 질문 확인 요청의 기대 주소를 현재 프록시 경로에 맞췄다. 음성 파일과 세션·요청 정보 전송, 잘못된 음성 답변 응답 거부를 검증하는 테스트를 추가했다.
- `frontend/tests/voice-input.test.js`: 음성 인식·답변 요청의 기대 주소를 현재 프록시 경로에 맞췄다. 음성 질문 확인 이후 세션·요청 정보가 전달되는지 검증하는 테스트를 추가했다.
- 이 작업 로그를 추가했다. 백엔드와 환경 변수 파일은 변경하지 않았다.

## 검증 결과

- `npm --prefix frontend test`: 49개 테스트 전부 통과했다. 음성 인식과 답변 API는 fetch 모의 응답으로 검증했으며 실제 마이크를 사용하지 않았다.
- `npm --prefix frontend run build`: Vite 프로덕션 빌드가 성공했다. 누락된 export 오류가 해소되었다.
- `git diff --check`: 통과했다.

## 남은 작업 및 제약

실제 음성·RAG 서버 호출, 브라우저 마이크 녹음 및 음성 재생은 이번 작업에서 검증하지 않았다. API 키나 외부 서비스 호출을 사용하지 않았다.
