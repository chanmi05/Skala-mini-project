# 평가 생성물 Git 추적 제외

- 작업일: 2026-10-26 (Asia/Seoul)
- 브랜치: rag-improve
- 상태: 정리·검증 완료

## 요청과 목적

비교·테스트를 위해 생성된 JSON 등 결과물을 정확히 확인하고 `.gitignore`에 추가한 뒤 현재 브랜치에 커밋·푸시한다.

## 수행 내용 및 변경 파일

- 시작 시 작업 트리는 깨끗했으며 현재 브랜치는 `rag-improve`, upstream은 `origin/rag-improve`였다. 기존 개선 코드·문서는 이미 커밋된 상태였다.
- 실행 코드와 생성 위치를 대조해 생성물 161개(3,384,644바이트)를 식별했다.
- `evaluation/runs/`: JSON 132개, JSONL 22개, 테스트 출력 TXT 2개.
- `evaluation/comparisons/`: 비교 집계 JSON 1개.
- `evaluation/inspections/`: 점검 JSON 1개와 스크린샷 PNG 1개.
- `evaluation/corpus.jsonl`: 인덱스 export 결과 1개.
- `data/eval/result.csv`: 검색 평가 결과 1개.
- 루트 `.gitignore`에 위 출력 디렉터리의 Markdown 이외 파일 및 코퍼스 export·검색 결과 CSV 제외 규칙을 추가했다. 전역 `*.json` 패턴은 사용하지 않았다.
- `git rm --cached`로 해당 161개의 추적만 해제했다. 로컬 파일은 삭제하지 않았다.
- 평가 입력·기대값, 소스·자동 테스트·평가 스크립트, Markdown 보고서, 설정 JSON과 공유 FAISS 인덱스는 유지했다.
- `rag-docs/rag-improve/평가_생성물_Git_제외_정책.md`에 전체 161개 경로와 유지/제외 기준을 기록했다.
- `evaluation/README.md`와 `RAG_서비스_개선_전후_비교_2026-10-26.md`에서 원자료가 로컬 보관 대상임을 명시하고 재실행·재집계 조건을 설명했다.
- 이번 작업에서는 서비스 코드를 변경하지 않았다.

## 검증 결과

- 161개 모두 로컬 파일 존재, Git 인덱스에서 제외, `git check-ignore` 적용을 확인했다.
- `evaluation/questions.jsonl`, `data/eval/eval_set.csv`, 문항별 비교 Markdown, 프런트엔드 설정 JSON의 Git 추적 유지 및 ignore 비적용을 확인했다.
- `.venv/bin/python -m unittest discover -s rag-service/tests`: 모의 모델·로컬 저장소 테스트 107/107 통과(3.037초). 외부 API 재평가는 수행하지 않았다.
- `git diff --check`, `git diff --cached --check` 통과.
- 커밋·푸시 대상은 추적 해제한 생성물과 이번 ignore·안내 문서·정책·작업 로그로 한정한다. 원격 반영은 푸시 후 Git 상태와 upstream 커밋 일치로 확인한다.

## 남은 작업 및 제약

- 새 체크아웃에는 원자료가 없으며 과거 실행 재집계에는 로컬 원자료가 필요하다. 새 결과는 평가 스크립트로 생성한다.
- 이번 변경은 새 커밋에서 추적을 해제하는 작업이다. 기존 커밋 이력은 다시 쓰지 않는다.
