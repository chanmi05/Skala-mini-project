# 휴가 낼게요

Vue 프런트엔드 실행:

```bash
cd frontend
npm install
npm run dev
```

접속: http://localhost:5173

- 사내 지침 챗봇: `/` (텍스트·음성 질문)
- 로그인: `/login`
- 회원가입: `/signup`

사내 지침 답변은 연결 준비 중이며, 실제 가입·로그인은 MariaDB와 Java 인증 서버(8080)를 실행해야 합니다. 음성 질문의 텍스트 변환은 기존 음성 서버(8008)를 사용합니다.

회원가입은 **이름·사원번호·비밀번호**, 로그인은 **사원번호·비밀번호**를 사용합니다. 로그인 후에는 가입한 이름으로 `홍길동님.`처럼 표시됩니다.
