# HWP 추출 실험

`Standard_Rules_of_Employment_2026.hwp`를 pyhwp로 실제 추출한 결과입니다.
원본 파일은 변경하지 않습니다. 외부 API나 LLM에 문서를 전송하지 않습니다.

## 실행

```bash
cd parse-hwp
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python extract.py Standard_Rules_of_Employment_2026.hwp
```

현재 Python 3.14.6에서 pyhwp 0.1b15, olefile 0.47, six 1.17.0,
lxml 7.0.0b1로 추출 실행을 확인했습니다. pyhwp는 오래된 패키지이므로
다른 Python/의존성 조합에서는 별도 호환성 확인이 필요합니다.

## 결과

`output/Standard_Rules_of_Employment_2026` 뒤에 아래 확장자가 붙습니다.

| 확장자 | 내용 |
|---|---|
| `.txt` | hwp5txt의 비교용 출력. 이 문서에서는 표가 `<표>`로 대체되어 본문 대부분이 빠짐 |
| `.xml` | pyhwp 구조 출력. 서식, 문단, 표·셀, 중첩 구조를 보관 |
| `.full.txt` | XML에서 표 내부까지 읽은 텍스트. 문단별 줄바꿈, XML 순서 |
| `.blocks.jsonl` | 비어 있지 않은 문단. 문단 ID, XML 경로, 중첩된 표·셀 좌표 포함 |
| `.tables.json` | 모든 표. 행·열, 셀 병합 범위, 셀 텍스트, 중첩 표 ID 포함 |
| `.paired_rows.jsonl` | 본문 비교표의 같은 행에 있는 규정안과 작성 지침을 분리해 연결 |
| `.report.json` | 추출 통계 및 한계 |

이 파일에서 확인한 수치:

- 비교용 TXT: 5,474자
- 표 내부를 포함한 문단 텍스트: 121,399자 (문단 사이 구분자 제외)
- XML 문단 2,367개 중 비어 있지 않은 문단 2,113개
- 표 45개, 셀 815개
- 규정안/작성 지침 비교표: table_id `5`, `27`, 각각 비어 있지 않은 데이터 행 118개
- `5`는 일반 근로자용, `27`은 단시간 근로자용 본문. 이 ID의 의미는 이 원본에 한정됨

문단 텍스트는 서식으로 쪼개진 Text 노드를 문단 안에서 이어 붙입니다.
문단 안의 중첩 표 텍스트는 해당 중첩 표의 문단으로만 추출하여 blocks/full.txt의
중복을 방지합니다. 셀 텍스트에는 중첩 표 내용도 포함하므로 tables.json의 상위 셀과
중첩 표를 모두 색인하면 중복이 생길 수 있습니다.

## RAG 설계 제안

현재 출력은 **중간 추출 결과**이며, 최종 청크나 벡터 DB는 아닙니다.

1. 일반 근로자용 / 단시간 근로자용 / 별첨을 먼저 구분합니다.
2. 목차, 계약서·통지서 양식, 규정안, 작성 지침을 구분합니다.
3. 규정안과 작성 지침은 같은 표 행의 출처 관계를 유지합니다.
4. 규정안은 조항 경계로 분리합니다. 한 셀에 제2조와 제3조가 같이 있는 사례가
   있으므로 한 행을 한 조항으로 가정하면 안 됩니다. 작성 지침을 두 조항에
   자동으로 일대일 대응시키는 것도 피해야 합니다.
5. 긴 조항은 항 단위로 나누고, 적용 대상·장·절·조 제목·상위 조항 ID를 붙입니다.
6. 참고 문안, 대체 문안, 중첩 표는 본문과의 관계를 유지합니다. 이미지·수식도
   별도 점검합니다. 특히 분수 형태 표는 행 순서 텍스트만으로 의미가 보존되지 않습니다.
7. 검색 시 적용 대상을 필터링하고, 필요할 때 연결된 지침이나 상위 조항을 조회합니다.

추출 결과에 있는 규정은 표준 문안이므로 특정 회사에 실제 적용 중인 규정이라는
의미를 부여하면 안 됩니다. 두 대상의 조항 번호도 다를 수 있습니다.

## 검증 범위

실제 파일로 TXT/XML 생성과 스크립트 실행을 확인했고, 문단 ID·XML 경로,
블록 ID 중복 여부, 두 비교표의 목적 조항과 지침 연결을 확인했습니다.
XML Text 노드가 문단에 속하는지 확인하며, 공백만 있는 문단은 제외합니다.

원본 HWP의 화면 전체와 대조한 검증은 수행하지 않았습니다. XML 순서가 시각적
읽기 순서와 일치한다고 보장하지 않습니다. OCR, 수식 해석, 정확한 페이지 매핑,
조항 분리, 참조 조항 연결, 검색 품질 평가는 아직 수행하지 않았습니다.
