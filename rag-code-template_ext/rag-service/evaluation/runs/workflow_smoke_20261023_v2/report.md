# LangChain·LangGraph 실제 연동 확인

공개 논문 저장소와 OpenAI 모델로 최종 코드의 6개 흐름을 확인했다. 기존 서버는 호출하지 않았다.
기대 상태 일치 여부는 실행 경로 확인이며 답변 정확도 점수가 아니다.

| 입력 | 상태 | 검색 횟수 | 모델 호출 | 전체 초 | 기대 상태 일치 |
|---|---|---|---|---|---|
| greeting | greeting | 0 | 0 | 0.00 | True |
| ambiguous | clarification_needed | 0 | 1 | 1.63 | True |
| document | answered | 1 | 3 | 4.85 | True |
| followup | answered | 1 | 3 | 3.94 | True |
| missing_fact | no_evidence | 2 | 4 | 5.64 | True |
| retrieval_gap | answered | 1 | 3 | 4.26 | True |

## 해석

- 인사는 모델·검색 호출 없이 종료했고, 모호한 입력은 검색 없이 확인 질문으로 종료했다.
- 일반 질문·후속 질문은 근거 확인 후 답했다. 각 문서 경로에서 모델 호출은 3회다.
- 환불 정보는 재검색 1회(총 검색 2회) 후 유보했다.
- 미래 토큰 마스킹 질문은 이 실행에서 최초 검색으로 충분한 근거를 확보했다. 재검색 개선 효과로 해석하지 않는다.
- 생성 답변의 인코더 6층·디코더 6층·마스킹 설명은 반환된 출처와 대조해 에이전트가 1차 확인했다.
- 문서 질의는 약 3.94~5.64초였다. 이전 단일 생성보다 호출 단계가 많으며 음성 전체 1~2초 목표를 충족했다고 볼 수 없다.
- 모델의 분류·근거 판단 품질과 최적 비용은 이 6개 사례만으로 검증되지 않는다.
- 이전 구현의 첫 실행은 workflow_smoke_20261023 폴더에 보존했고 최종 예산 보정 코드의 검증은 이 v2 결과다.
- 실제 함수·모듈 해시는 manifest.json에 기록했고 현재 코드와 일치함을 확인했다.
- 기존 인덱스 해시는 실행 전후 동일하다.

## document

논문에서 기본 Transformer 인코더는 몇 개 층이며 하위 계층은 무엇인가요?

기본 Transformer 인코더는 6개의 동일한 층으로 구성되어 있습니다. 각 층은 두 개의 하위 계층으로 이루어져 있습니다. 첫 번째 하위 계층은 멀티-헤드 셀프 어텐션 메커니즘이고, 두 번째 하위 계층은 위치별 완전 연결 피드 포워드 네트워크입니다. 각 하위 계층에는 잔차 연결이 적용되며, 그 후 층 정규화가 수행됩니다 [S3].

종료 사유: evidence_sufficient

## followup

그럼 디코더는 몇 층인가요?

논문의 기본 Transformer 디코더는 6개의 층으로 구성되어 있습니다 [S3].

종료 사유: evidence_sufficient

## missing_fact

이 논문에서 Transformer 구매 고객의 환불 기간은 며칠인가요?

제공된 문서에서 답변에 사용할 근거를 찾지 못했습니다.

종료 사유: retry_limit

## retrieval_gap

디코더가 아직 생성하지 않은 미래 토큰을 보지 못하게 하는 방법은 무엇인가요?

디코더가 아직 생성하지 않은 미래 토큰을 보지 못하게 하기 위해서는 디코더의 자기-어텐션(self-attention) 레이어에서 마스킹을 사용합니다. 이는 스케일드 닷-프로덕트 어텐션(scaled dot-product attention) 내에서 소프트맥스 입력의 불법적인 연결에 해당하는 모든 값을 -∞로 설정하여 구현됩니다. 이렇게 하면 디코더의 각 위치가 해당 위치까지의 모든 위치에만 주의를 기울일 수 있게 되어, 오토-회귀(auto-regressive) 특성을 유지할 수 있습니다 [S1].

종료 사유: evidence_sufficient
