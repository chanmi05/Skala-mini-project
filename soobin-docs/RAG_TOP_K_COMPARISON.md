# RAG top_k 비교 평가

작업일: 2026-10-23 (Asia/Seoul)

## 실험 조건

기존 k=5 평가 결과를 보존하고 k=3, 7, 10을 각각 24개 질문으로 추가 실행했다.
추가 실제 호출은 72건이며 모두 성공했다. 기존 기준을 포함한 비교 대상은 96건이다.

- 자료: 「Attention Is All You Need」 기존 44개 청크.
- 질문: 답변 가능 20개, 답변 불가 4개. 실패 질문 7개의 기대 근거를 재확인했고 변경하지 않았다.
- 모델: GPT-4o, temperature=0, 출력 최대 600토큰.
- 임베딩: 기존 서버 기본값과 같은 text-embedding-ada-002.
- 입력 예산: 6,000토큰. 같은 RAG 모듈·질문·인덱스·패키지 버전 유지.
- 각 설정 1회, 추가 실행은 순차 수행. k=5는 이전 실행이므로 캐시·시간·네트워크 조건은 통제하지 않았다.

## 결과

|---|---|---|---|---|---|---|
| 3 | 12/20 | 60% | 60% / 60% | 1.63초 | 1,019 | 3 |
| 5 | 13/20 | 65% | 65% / 65% | 1.78초 | 1,633 | 5 |
| 7 | 16/20 | 80% | 80% / 80% | 1.69초 | 2,222 | 7 |
| 10 | 18/20 | 90% | 90% / 90% | 1.77초 | 3,085 | 10 |

검색률은 답변 가능 질문 20개 기준이다. 시간·평균 토큰은 전체 24개 기준이다.
토큰 수는 제공자가 반환한 usage를 사용했으며 추정 글자 수가 아니다.
현재 질문에서는 입력 예산 때문에 추가로 빠진 청크가 없었다.

k=10의 검색 성공은 k=5 대비 25%p 높고, 평균 입력 토큰은 약 89% 증가했다.
시간 차이는 반복 실험으로 검증한 효과가 아니므로 ‘k=10이 더 빠르다’고 해석하지 않는다.
STT·TTS와 화면 전달 시간은 포함하지 않았으며 첫 토큰 시간도 측정하지 않았다.

## 답변 사례 검토

실패·복구 질문과 답변 불가 질문의 답변을 에이전트가 1차 검토했다.
전 설정의 답변을 동일 루브릭으로 완전 채점한 정확도 비교는 수행하지 않았다.

- q08: k=7부터 512/2048을 담은 근거가 들어왔고 두 차원을 답했다.
- q17: k=7부터 perplexity 악화·정확도/BLEU 개선을 포함한 근거와 답변이 확인됐다.
- q20: k=7부터 영어 구문 분석 적용을 확인하는 답변이 나왔다.
- q10: k=10에서 긴 길이 외삽을 담은 근거와 답변이 확인됐다.
- q16: k=10에서 원문이 요구하는 하위 계층 출력 및 임베딩·위치 인코딩 합의 적용 위치를 답했다.
- q03: 모든 설정에서 핵심 근거를 놓쳤고 답변을 유보했다.
- q09: k=7은 개요 청크를 인용했고, k=10은 sinusoidal positional encoding을 언급하는
  변형 실험 청크를 인용했다. 하지만 순서 반영 방식과 사인·코사인을 직접 설명하는
  지정 근거 그룹은 여전히 누락돼 인용의 충분성을 별도 점검해야 한다.
- 새 실행의 답변 불가 질문은 3개 설정 × 4개 모두 정보 부재를 안내했다.
  이는 제한된 사례의 에이전트 검토이며 일반적인 환각 방지 성능을 뜻하지 않는다.

정답 기준·사례 검토는 독립적인 사람의 검증을 받지 않았다. 개선 전후 판단을 위해
같은 질문 기준을 보존했고, 검색률을 답변 정확도로 표시하지 않았다.

## 개발 판단

이 질문 세트에서는 **k=10을 다음 검색 전략 비교의 후보 설정**으로 삼을 근거가 생겼다.
다만 운영 기본값은 아직 5로 유지했다. 검색 범위를 넓히면 입력 비용과 무관한 자료도 늘어난다.

다음에는 미해결 q03/q09를 중심으로 검색용 질문의 영문 핵심 용어 보완 또는 질의 정리를
평가하고, 이후 후보 확대 후 재순위화 방식을 검토한다. 모델·질문·기준 결과는 유지한다.
기본값 확정 전에는 반복 지연 측정과 답변·인용 품질의 추가 검증이 필요하다.
